AI Output Review Scorecard

Review an AI-generated answer using a consistent rubric. Score each criterion, record evidence and concerns, and export a CSV review record. This is a structured aid for human judgment—not proof that an answer is correct.

Review details

Score the answer

Each criterion is scored from 0 to 5. The weights total 100%. Use the evidence field to explain each score. The default weights are a practical starting point; adjust them to fit your task.

How to use the result

  • Keep the original prompt and answer if you need a reproducible evaluation.
  • Score against the task and available evidence—not against confidence or writing polish alone.
  • For important factual claims, verify them against reliable sources independently.
  • Do not treat scores from different reviewers as directly comparable unless they use the same rubric and process.
