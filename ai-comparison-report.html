Compare up to three AI responses to the same task. Use the same rubric for each output, capture evidence, and export a report you can inspect in a spreadsheet. The tool does not decide which answer is true; you must verify claims against reliable sources.

Fair-comparison checklist

  • Use the same prompt, context, reference documents, and output requirements for each model.
  • Record model names, versions, run dates, and settings separately when known; never guess missing metadata.
  • Use neutral labels during scoring if possible, and verify factual claims against the same sources.
  • Report the rubric, weights, limitations, and missing information alongside any conclusion.
