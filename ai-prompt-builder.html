Use it responsibly

  • A detailed prompt can improve clarity, but it cannot guarantee a correct answer.
  • For factual or academic work, compare important claims with reliable source material.
  • Do not paste passwords, private records, or confidential information into prompts.
  • For coding tasks, run and test the generated code before relying on it.
